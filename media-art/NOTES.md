공통 후처리는 작품 로직과 분리한다. UE 이식 시 CSS 비네팅은 포스트 프로세스 볼륨의 **Vignette Intensity**, 그레인은 **Film Grain**, 블룸 캔버스의 밝기 임계값과 강도는 **Bloom Threshold·Bloom Intensity**에 대응한다.

## 라운드별 변경 이력

- **1차:** 네 작품의 3막, 손 반응, 공통 48초 시계와 검증 훅을 만든 시제품. 선과 빛의 밀도가 부족했다.
- **2차:** 숲의 필획·바다의 흐름장·우주의 궤도 호·꽃밭의 개화 곡선으로 시각 언어를 다시 구성했다. 장면이 무거워졌다.
- **3차:** 숲 획 최대 450개, 바다 속도장 64×36 격자, 우주 호 최대 450개, 꽃밭 최대 78개로 조정했다. 실제 경과 시간과 재생 재개 시각을 분리해 시계 오차를 바로잡았다.
- **4차:** 숲에는 파도가 지나가는 폭 25%의 밝은 띠와 가늘어지는 붓끝을 추가했다. 꽃밭은 2·3·5차 장미 곡선과 최소 간격으로 고리의 중첩을 줄이고 장미색을 주색으로 바로잡았다. 바다는 시각 구성과 64×36 격자를 유지하며 와류 감쇠를 와류당 한 번만 계산하도록 바꿨다. 공개 화면에서 장소 표기를 일반 표현으로 교체했다.
- **5차:** 모든 작품에 1/4 해상도 합성 블룸, 작품색이 섞인 암부, 미리 만든 비네팅과 낮은 알파의 필름 그레인을 적용했다. 선 끝은 둥글게 하고 중요한 근경 선은 흐린 외곽과 선명한 중심을 겹쳤다. 숲의 안개와 포자에 빛을 더했고, 바다는 밝은 근경 결의 이중 획, 와류의 은은한 반짝임과 진주빛 끝점을, 우주는 밝은 머리·사라지는 꼬리와 회절 별·희미한 원경 먼지를, 꽃밭은 곡선 필라멘트와 불규칙한 수묵 자국을 더했다. 이 후처리는 프레임당 한 번만 실행한다.
- **6차:** 블룸 버퍼를 화면 크기와 무관한 256×144로 고정하고 두 프레임마다 다시 계산한다. 축소 복사한 화면에서 채널값 34 이하를 제거해 어두운 바탕은 번지지 않게 했다. 네 작품의 바탕을 채널별 12 이하의 거의 검정으로 낮추고 그레인 알파를 최대 2/255로 제한했다. 바다의 넓은 외곽 획은 전체 궤적의 약 10%만 그린다. 꽃밭의 번짐은 회전된 잡음 좌표와 옅은 안쪽·짙은 가장자리로 만든 물감 링 4종으로 바꿨다.
- **7차:** 화면 전체 비네팅과 그레인을 캔버스 그리기에서 `#stage` 안의 CSS 레이어로 옮겼다. 그레인 타일은 시작 시 한 번 이미지로 만들어 CSS 배경 위치만 바꾼다. 블룸도 별도 320×180 캔버스로 분리해 두 프레임마다 메인 화면을 축소 복사하고 임계값을 적용한다. 브라우저가 CSS blur와 screen 합성을 담당하며 메인 캔버스에는 다시 확대 그리지 않는다. 작품별 획·궤적과 손 반응은 그대로다.
- **8차:** 바다만 80×45 속도장으로 바꿨다. 기본 결·시간 노이즈·썰물 끌림을 격자에 한 번 채우고, 와류마다 영향 반경 안의 격자 칸만 갱신한다. 입자는 와류 목록을 보지 않고 쌍선형 보간값만 읽는다. 입자 시작 높이의 파형은 위상을 typed array에 미리 저장해 프레임당 삼각함수 두 번으로 계산한다. 손 와류는 20초 뒤 배열 안에서 제자리 압축하며 최대 40개를 유지한다. 경로 수와 획의 색·굵기, CSS 후처리는 유지했다.
- **9차:** 3초 프로파일에서 블룸의 `getImageData`가 rAF 콜백 자체 시간의 77.3%를 차지했다. 프레임 경로의 픽셀 읽기·쓰기를 없애고, 320×180 블룸 캔버스에는 메인 화면 축소 복사만 두 프레임마다 수행한다. 밝기 임계값은 CSS의 `brightness(.84) contrast(1.29) blur(8px)`로 옮겼다. 이 수치는 이전 채널 임계값 34와 밝기 기울기에 가깝게 맞춘 것이다. 픽셀 읽기 최적화 옵션도 제거해 그래픽 가속 경로를 유지한다. 노이즈 타일의 이미지 생성은 시작할 때 한 번만 수행한다.
- **10차:** 숲의 짧은 세로 획을 모두 제거하고 빛줄기 10개, 빛 사이의 어둠, 서로 다른 속도로 흐르는 안개 3층으로 다시 만들었다. 1막은 낮은 안개와 늦게 나타나는 소수의 빛, 2막은 6.5초 호흡과 좌우 0.8초 시차, 3막은 끊기는 빛과 떠오르는 포자로 구성했다. 바람은 손 위치의 안개를 가르고 빛줄기를 휘게 한다. 빛·안개·바람 자국은 초기화 때 만든 스프라이트를 재사용하고 포자는 typed array와 묶은 `Path2D`로 그린다. 다른 세 작품과 공통 후처리는 유지했다.

## 제출 전 확인

- [x] 썸네일 조형 원리: 넓은 빛줄기와 안개 / 흐름 결 / 기울어진 호 / 장미 곡선.
- [x] 막 변화: 숲은 안개→함께 숨 쉬는 빛→포자, 바다는 평행 결→와류→나선, 우주는 폭발→호→한 점, 꽃밭은 씨앗→개화→낙화다.
- [x] 즉시 손 반응: 바람은 안개 빈터와 빛줄기 휘청임, 바다는 빈 원, 우주는 금빛 별, 꽃밭은 햇빛이다.
- [x] 고정 카메라의 2D 평면으로 만들었고, 작품별 UE 계열은 두 개 이하다.
- [x] 48초 순환, 막 버튼, 키보드, 가상 손, 폭 400px 레이아웃, `window.__proto` 훅을 유지했다.
- [x] 매 프레임 그라디언트 생성 없이 미리 만든 빛 스프라이트를 사용한다. 선은 단계별 `Path2D`로 묶는다.
- [x] 4차 자동 검증에서 콘솔 오류 0, 최저 59fps, 막 점프 오차 0, 시간 정확, 모바일 넘침 0을 확인했다.
- [x] 6차 자동 검증에서 블랙 레벨과 꽃밭 얼룩을 확인했다. 7차 목표인 같은 조건의 4차 대비 비용 증가 10% 이내는 재측정이 필요하다.
- [x] 8차 내장 그래픽 검증에서 바다 2막은 20fps였고, 프로파일에서 픽셀 읽기가 주된 병목으로 확인됐다. 9차의 성능과 모서리 밝기 14 이하 유지 여부는 같은 장비에서 재측정해야 한다.
- [x] 10차 숲의 세 막은 문법 검사로 확인했다. 실제 화면, 손 반응, 내장 그래픽 55fps는 전시 장비에서 다시 측정해야 한다.
