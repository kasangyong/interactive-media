# 브리프: 추상의 네 장면 (전시용 실시간 인터랙티브 미디어아트 웹 시제품)

> 2026-10-14 브리프 요약(공개용으로 회사·인명 정보를 뺌).

## 배경
- 대형 전시장 벽면 LED·프로젝션, AI 기반 실시간 인터랙티브 미디어아트. 관람객은 손 동작으로 상호작용(카메라가 손 위치 추적).
- 작품 하나 30초~1분, 끝나면 다음 작품으로 자동 교체. 테마: 숲 / 바다 / 우주 / 꽃밭.
- 클라이언트 요구: 작품마다 추상적인 형태를 예술적으로 시각화하고, 컨셉과 스토리텔링을 더한다. 사실적 묘사 금지. 각 작품이 하나의 생각을 말하고 시간에 따라 이야기가 흐른다.
- 최종은 Unreal Engine 5. 이 시제품은 방향을 정하기 위한 웹 시제품이며 UE 제약을 지켜야 한다.

## 작품마다 정할 것
1. 컨셉 한 문장 (보여 주는 것이 아니라 말하는 것)
2. 3막 이야기 48초: 1막 0~14 / 2막 14~36 / 3막 36~48. 3막 끝은 화면을 비우거나 한 점으로 모은다(다음 작품으로 가는 문).
3. 손의 의미 (바람, 햇빛, 또 하나의 별 등). 반응은 의미에서 자연스럽게 나오고, 누구나 1초 안에 알아챌 만큼 직관적이어야 한다.
4. UE로 옮기는 방법 (아래 8계열 중 1~2개, 필요한 파일)

## 미술 방향
- 추상이 기본. 선, 점, 입자, 흐름, 장, 빛의 번짐. 객체는 암시만.
- 작품마다 시각 언어가 달라야 한다(같은 입자 효과에 색만 바꾸면 실패). 예: 숲=세로 선 리듬, 바다=흐름장 궤적, 우주=궤도와 중력, 꽃밭=극좌표 곡선과 번짐.
- 색은 작품당 2~3색. 검은 바탕 위의 빛, 가산 혼합. 채도 높은 무지개색 금지.
- 움직임에 호흡(느림/빠름, 정지/폭발 대비). 막 전환은 분명하되 3~6초에 걸쳐.
- 참고 감각: teamLab, Ryoji Ikeda의 절제, 흐름장 제너러티브 아트, 수묵의 번짐. 표절 금지.
- 화면 안 글자 금지(제목 캡션만 구석에 작게).

## 인터랙션 규칙
- 마우스·터치 포인터 = 손. 손이 2초 이상 없으면 가상 손이 2막 동안 돌아다니며 시연("가상 손" 표시).
- 손 위치에 얇은 원(잔상 없는 DOM/별도 레이어).
- 멈춘 손(위치 반응)과 움직이는 손(속도 반응)을 구분.
- 반응 계산은 손 목록을 받는 구조.

## UE 제약: 8계열
1 객체 반응(꽃·새·물고기·빛 구슬·새싹이 피기·빛나기·피하기·다가오기) / 2 표면 그리기·혼합 / 3 입자·흐름(밀림·회전·리본·수명) / 4 영역·미디어 / 5 표면·형태 변형(파문·탄성) / 6 유체·장(ImageFlow 포함) / 7 군집 / 8 시청각.
- 카메라 고정(화면 전체 회전·줌 금지), 2D 평면 기본, 깊이는 크기·밝기·속도로만.
- 손 반응은 속도·반경·세기·지속 시간·복원 시간 같은 숫자로 설명 가능해야 한다.
- 생성 AI 외부 파일은 배경 이미지, 패널용 이미지·영상, ImageFlow 원본 이미지, 객체 피부 이미지뿐.

## 기술
- 단일 HTML, 외부 이미지·폰트 없음. CDN은 꼭 필요할 때 버전 고정 1~2개.
- 노트북 내장 그래픽 60fps 목표, DPR ≤ 2, 입자 수는 면적 비례+상한, dt 기반.
- 16:9 상영 영역, 리사이즈 재계산, 폭 400px에서 깨지지 않음.
- 48초 자동 이동·순환, 일시정지/재생, 작품 탭, 막 버튼(해당 막 상태로 바로 진입).
- 설명 패널(한국어): 컨셉, 손의 의미, 3막(현재 막 강조), UE 계열과 필요한 파일.
- 키보드 조작, prefers-reduced-motion이면 일시정지로 시작.
- 작품별 객체(init, step(dt, t, hands), seek(t)).

## 하지 말 것
사실적 묘사(이모지·클립아트·사진 포함), 같은 입자 시스템 색만 바꾸기, 카메라 회전·줌·3D 비행, 화면 중앙 큰 글자, 미묘해서 모르는 반응, 48초 내내 같은 상태.
