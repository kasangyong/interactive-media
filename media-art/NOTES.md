## 라운드별 변경 이력

- **1차:** 네 작품의 3막, 손 반응, 공통 48초 시계와 검증 훅을 만든 시제품. 선과 빛의 밀도가 부족했다.
- **2차:** 숲의 필획·바다의 흐름장·우주의 궤도 호·꽃밭의 개화 곡선으로 시각 언어를 다시 구성했다. 장면이 무거워졌다.
- **3차:** 숲 획 최대 450개, 바다 속도장 64×36 격자, 우주 호 최대 450개, 꽃밭 최대 78개로 조정했다. 실제 경과 시간과 재생 재개 시각을 분리해 시계 오차를 바로잡았다.
- **4차:** 숲에는 파도가 지나가는 폭 25%의 밝은 띠와 가늘어지는 붓끝을 추가했다. 꽃밭은 2·3·5차 장미 곡선과 최소 간격으로 고리의 중첩을 줄이고 장미색을 주색으로 바로잡았다. 바다는 시각 구성과 64×36 격자를 유지하며 와류 감쇠를 와류당 한 번만 계산하도록 바꿨다. 공개 화면에서 장소 표기를 일반 표현으로 교체했다.

## 제출 전 확인

- [x] 썸네일 조형 원리: 세로 획 / 흐름 결 / 기울어진 호 / 장미 곡선.
- [x] 막 변화: 숲은 획→숨의 띠→포자, 바다는 평행 결→와류→나선, 우주는 폭발→호→한 점, 꽃밭은 씨앗→개화→낙화다.
- [x] 즉시 손 반응: 바람은 획 변위, 바다는 빈 원, 우주는 금빛 별, 꽃밭은 햇빛이다.
- [x] 고정 카메라의 2D 평면으로 만들었고, 작품별 UE 계열은 두 개 이하다.
- [x] 48초 순환, 막 버튼, 키보드, 가상 손, 폭 400px 레이아웃, `window.__proto` 훅을 유지했다.
- [x] 매 프레임 그라디언트 생성 없이 미리 만든 빛 스프라이트를 사용한다. 선은 단계별 `Path2D`로 묶는다.
- [x] 3차 자동 검증에서 콘솔 오류 0, 막 점프 오차 0, 시간 2.00초/2초, 모바일 넘침 0을 확인했다. 4차 수정 후 바다 2막 55fps 목표는 재측정이 필요하다.
