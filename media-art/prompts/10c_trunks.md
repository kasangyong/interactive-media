# 10차 다듬기 — 나무 기둥 마스크

새 숲은 좋다(빛줄기·안개·포자 분위기 합격, 오류 0, 숲 세 장면 60fps). 한 가지만 고친다.

나무 기둥을 암시하는 **어두운 직사각형 마스크**가 화면에서 결함처럼 보인다.
- 좌우 가장자리가 칼로 자른 듯 딱딱하다 → 가장자리 양쪽 15~25%를 부드러운 그라데이션으로 (미리 만든 가로 그라데이션 스프라이트를 세로로 늘여 사용).
- 화면 중간 높이(약 70%)에서 바닥이 평평하게 잘린다 → 기둥은 화면 아래까지 이어지되, 아래 1/3에서 안개 속으로 서서히 사라지게(세로 알파 그라데이션). 평평한 끝선이 보이면 안 된다.
- 기둥 폭을 서로 다르게(화면 폭의 1.5~5%), 원경 기둥은 더 옅고 가늘게, 근경 기둥 1~2개는 더 넓고 짙게. 수직에서 1~3° 정도만 미세하게 기울여 기계적인 느낌을 없앤다.
- 기둥은 "검은 막대"가 아니라 빛줄기를 가리는 그림자로만 읽혀야 한다. 빛줄기와 겹치는 곳에서만 어둠이 드러나게(빛이 없는 곳에서는 배경과 구분되지 않아도 된다).

다른 것은 손대지 말 것. git commit 금지, 폴더 밖 수정 금지.
