# 4차 연출 지시 — 마지막 다듬기

자동 검증(3차): 콘솔 오류 0, 막 점프 오차 0, 시간 2.00초/2초, 모바일 넘침 0, fps는 11장면 60 / **바다 2막만 49**. 스크린샷 `shots/r3/sheet.jpg` 가 열리지 않으면 아래 설명만으로 판단하라.

3차는 좋아졌다. 네 작품 모두 1→2→3막 변화가 썸네일로 읽힌다. 바다·우주는 그대로 유지. 이번이 마지막 라운드다.

## 1. 바다 2막 성능 49 → 55fps 이상
소용돌이가 많아지는 2막에서 떨어진다. 소용돌이 속도장을 저해상도 격자(예: 화면 비율 64×36)에 프레임당 한 번만 계산하고, 입자는 격자를 쌍선형 보간으로 읽어라. 입자마다 소용돌이 목록을 순회하지 말 것. 시각 결과는 지금과 같아야 한다.

## 2. 숲 — 호흡이 보이게, 획에 붓맛
- 2막 핵심인 **숨의 파도**가 썸네일에서 안 보인다. 6.5초 주기의 숨이 왼쪽→오른쪽으로 건너갈 때, 파도가 지나는 폭(화면 폭의 25%) 안의 획은 밝기 1.8배 + 획 끝 위로 0.08H 상승 + 안개색으로 변하게 하라. 어느 순간을 캡처해도 "밝은 띠가 숲을 건너는 중"이 보여야 한다.
- 획이 모두 균일한 직선이라 단조롭다. 획마다 위로 갈수록 가늘어지고(아래 굵기의 30%까지), 위 1/4은 알파가 0으로 사라지게(붓끝). 3단 깊이 대비(먼 획 알파 0.08, 가까운 획 0.55)를 지금보다 분명히.
- 3막·1막은 유지.

## 3. 꽃밭 2막 — 엉킨 낙서처럼 보임
- 곡선들이 겹치고 고리가 많아 낙서(doodle)처럼 보인다. k는 {2, 3, 5}만(고리가 적고 꽃잎이 분명한 장미 곡선), 같은 자리 겹침을 피하도록 꽃 사이 최소 간격 = 두 반지름 합의 0.7배.
- **색 관계가 뒤집혔다.** 장미색이 주색(곡선 80%), 금빛은 꽃 중심의 작은 점과 손의 햇빛에만. 지금은 금빛 곡선이 너무 많다.
- 큰 꽃 3~5송이(반지름 = 화면 높이의 0.12~0.16)는 선 굵기 1.4px로 또렷하게, 작은 꽃은 0.7px로 흐리게. 화면에 여백이 30% 이상 남게.
- 3막(번진 자국 + 흘러내리는 실)은 지금 좋다. 유지.
