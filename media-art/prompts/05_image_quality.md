# 5차 연출 지시 — 이미지 퀄리티

4차는 자동 검증을 모두 통과했다(오류 0, 최저 59fps, 막 점프 오차 0, 시간 정확, 모바일 정상). 구성과 이야기는 이제 합격이다. 이번 라운드는 **한 프레임 한 프레임의 이미지 퀄리티**만 올린다. 이 작품은 1920×1080 MP4·GIF·스틸로도 뽑혀 전시 제안서와 영상에 쓰인다. 캡처 한 장을 4K 모니터에 띄웠을 때 "고급 미디어아트 스튜디오의 스틸"로 보여야 한다. 지금은 "가는 선이 그려진 캔버스 데모"로 보인다.

접촉 시트: `shots/r4/sheet.jpg` (열리지 않으면 아래 설명으로 판단)

## 공통 렌더링 기법 (모든 작품에 적용, 성능 기준 유지: 모든 장면 55fps 이상)
1. **빛 번짐(블룸)**: 밝은 선·점 주변에 부드러운 빛 무리를 둔다. 방법: 메인 캔버스를 1/4 해상도 오프스크린 캔버스에 `drawImage`로 축소 복사 → 그 작은 캔버스를 `globalCompositeOperation = 'lighter'`, `globalAlpha 0.35~0.6`으로 원래 크기로 확대해 다시 얹는다(축소·확대만으로 블러 효과). 필요하면 1/8 해상도로 한 번 더. `filter: blur()`·`shadowBlur`는 쓰지 않는다(느림).
2. **빛의 계조**: 같은 획이라도 중심은 밝고 가장자리는 어둡게. 굵은 획·중요한 획은 "넓고 흐린 선(알파 0.08, 굵기 4~6px) + 가늘고 밝은 선(1px)" 두 겹으로 그려 빛나는 필라멘트처럼.
3. **깊이 3층**: 원경(흐림·어두움·느림), 중경, 근경(선명·밝음·빠름). 원경은 블룸을 더 세게 받아 안개처럼 보이게.
4. **색 보정**: 각 작품의 2~3색 안에서 그림자 쪽은 색을 머금은 검정(순수 #000 대신 작품색이 아주 살짝 섞인 거의 검정), 하이라이트는 거의 흰색까지 올라가되 색조는 유지. 비네팅(가장자리 10~15% 어둡게)을 스프라이트 한 장으로.
5. **필름 그레인**: 아주 약한 노이즈(알파 0.03~0.05)를 미리 만든 노이즈 타일 캔버스로 매 프레임 위치만 바꿔 덮는다. 계조 밴딩(색 띠)도 줄어든다.
6. **선 품질**: `lineCap = 'round'`, `lineJoin = 'round'`. 1px 미만 선은 알파로 표현. 고 DPR(최대 2)에서 선이 가늘게 사라지지 않게 굵기를 CSS px 기준으로 유지.

## 작품별
- **숲**: 지금 가장 약하다. 안개는 화면 아래 1/3을 덮는 여러 겹의 빛 층(원경 안개는 블룸으로 번짐). 획은 붓끝처럼 위로 갈수록 가늘고 흐려지고, 근경 획 10%는 두 겹 필라멘트. 2막 **숨의 띠**가 건너갈 때 그 띠 안의 획과 안개가 함께 밝아져 화면에 밝은 파도가 분명히 보이게(어느 프레임을 캡처해도). 3막 포자는 금빛 점마다 작은 빛 무리(스프라이트).
- **바다**: 궤적이 1px 실선 한 종류뿐이라 평평하다. 궤적 굵기·밝기 3층, 소용돌이 중심부로 갈수록 밝고 촘촘하게(물의 반짝임). 블룸으로 결 전체가 은은히 빛나게. 3막 마지막 한 점은 블룸이 있는 진주빛 점.
- **우주**: 호(arc)는 머리 쪽이 밝고 꼬리로 갈수록 사라지게(혜성 꼬리). 별 일부(10%)는 십자 회절 스파이크가 있는 작은 별 스프라이트. 손의 금빛 별은 블룸이 있는 진짜 별처럼. 배경에 아주 희미한 원경 별 먼지(알파 0.05, 움직임 거의 없음).
- **꽃밭**: 곡선 두 겹(넓고 흐린 빛 + 가늘고 밝은 선)으로 꽃잎이 빛나게. 꽃 중심은 블룸이 있는 금빛 점. 3막 번진 자국은 가장자리가 불규칙한 수묵 얼룩(원형 스프라이트 대신 노이즈로 일그러진 얼룩 스프라이트 3~4종을 미리 만들어 회전·크기 변화로 사용).
