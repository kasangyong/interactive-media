# 3차 연출 지시 — 디렉터 피드백 (자동 검증 결과 포함)

스크린샷: `shots/codex-r2/sheet.jpg` (행: 숲·바다·우주·꽃밭 / 열: 9초·25초·41.5초)

## 잘한 것 — 건드리지 말 것 (성능 최적화만 허용)
- **바다**: 1막 평행한 결 → 2막 거대한 소용돌이 → 3막 중앙으로 빨려 드는 나선. 썸네일만으로 이야기가 읽힌다. 시각 언어 유지.
- **우주**: 1막 방사형 폭발 → 2막 기울어진 호들이 엮인 직물 → 3막 한 점. 유지.

## 1. 성능 — 최우선 (헤드리스 Chromium 1280×720 측정, 2차)
| 장면 | fps | | 장면 | fps |
|---|---|---|---|---|
| 숲 1막 | **13** | | 우주 2막 | 37 |
| 숲 2막 | **7** | | 꽃밭 2막 | 34 |
| 바다 2막 | **15** | | 꽃밭 3막 | 24 |
| 바다 3막 | 49 | | 숲 3막 | 50 |
(1차는 12장면 모두 60fps였다.) **모든 장면 55fps 이상**이 합격선이다. 원인을 코드에서 찾아 고쳐라. 점검 목록:
- 획·궤적을 개별 `stroke()`로 그리고 있지 않은가 → 색·굵기별 `Path2D` 몇 개로 묶어 프레임당 stroke 호출 10회 이하.
- 매 프레임 `ctx.lineWidth`/`strokeStyle`을 객체마다 바꾸고 있지 않은가 → 단계(tier)로 양자화해 묶는다.
- 숲 획의 분절 수가 과도하지 않은가 → 획당 8~12 분절, 획 수는 면적 비례 상한 450.
- 바다 입자 × 소용돌이 이중 루프 → 소용돌이 영향 반경 밖은 즉시 continue, 소용돌이 최대 40개, 입자 상한 2000. 필요하면 소용돌이 속도장을 저해상도 격자(예: 64×36)에 프레임당 한 번 계산하고 입자는 격자 보간으로 읽어라.
- 매 프레임 `createRadialGradient`·`createLinearGradient`·`shadowBlur`·`filter` 사용 금지(스프라이트 사용). `shadowBlur`는 특히 치명적이다.
- 전체 화면 반투명 fillRect(잔상)는 프레임당 1회만.

## 2. 시간 정확도 버그
실제 2초 동안 작품 시계가 **2.22초** 흘렀다(1차는 2.00). 서브스텝을 돌리며 시계를 서브스텝마다 더하는지, 실제 경과와 서브스텝 합이 이중으로 누적되는지 확인하라. 실제 경과 시간 = 작품 시간, 서브스텝은 물리만.

## 3. 숲 — 다시 연출
현재 1막과 2막이 청록색 벽으로 화면을 꽉 채워 구별이 안 되고, 깊이도 호흡도 보이지 않는다. 채도 높은 단색 벽은 브리프의 절제와도 어긋난다.
- **밀도 40% 감소**, 획 사이 어둠이 보여야 숲의 결이 보인다.
- **깊이 3단**: 먼 획(다수) 알파 0.06~0.1·0.7px·짧음, 중간 0.2~0.3·1px, 가까운 획(소수 10%) 0.45~0.6·1.6px·키 큼. 가까운 획만 안개색(밝은 회청록)으로, 먼 획은 이끼색으로.
- **1막 안개**: 획은 화면 아래 절반까지만 자란다. 화면 아래 1/3을 덮는 낮은 안개 빛(스프라이트 띠)이 주인공. 10초에도 위쪽 절반은 거의 어둡다.
- **2막 호흡**: 획이 위로 끝까지 자라고, 6.5초 주기로 숲 전체 광량이 0.5배↔1.6배로 크게 오르내린다. 숨의 파도가 왼쪽→오른쪽으로 건너간다. 숨이 차오를 때 획 끝이 위로 0.1H 늘어난다. 썸네일 한 장에서도 "밝은 띠가 숲을 건너는 중"이 보여야 한다.
- 3막은 지금 방향(아래부터 풀려 떠오르는 포자) 유지. 다만 포자는 금빛(세 번째 색)으로, 41초에 획은 거의 남지 않아야 한다.
- 손(바람): 획이 손을 피해 휘는 빈터는 유지. 손 자리에 빛을 그리지 말 것.

## 4. 꽃밭 — 다듬기
- **곡선이 각졌다**(육각형처럼 보임). 샘플 수를 반지름에 비례시켜라: `N = clamp(r * 2.2, 48, 220)`. 큰 꽃은 매끈해야 한다.
- 2막은 방향이 좋다(크기 차이, 그려지는 곡선). 단 큰 꽃 몇 송이(화면 높이 1/4~1/3)가 분명히 있어야 하고, 꽃 중심의 금빛은 작은 점으로만.
- **3막 낙화가 빗줄기처럼 수직 직선**이다. 실은 바람에 날리듯 대각선으로 휘며 흘러내리고(곡선, 개체마다 방향·속도 차이), 수는 절반으로. 꽃이 있던 자리의 **번진 자국**(자두·장미색 부드러운 얼룩, 스프라이트 `drawImage`)이 41초 화면의 주인공이어야 한다. 46~48초에 자국까지 사라져 빈 화면.
